# Fiji Ministry of Education — Year 9 Basic Technology Materials

This directory is reserved for the Year 9 Basic Technology source materials used by IA-Tutor for the Industrial Arts research prototype.

## Source materials

- `BT Yr 9 Workbook(1).pdf` — Year 9 Student Workbook, Technical Employment Skills and Training, Ministry of Education, Fiji (2019).
- `YEAR 9 Basic Technology Textbook.pdf` — Year 9 Basic Technology textbook, Ministry of Education, Fiji (2018).

## Intended IA-Tutor use

The materials are used as the source corpus for Year 9 Industrial Arts/Basic Technology tutoring, including technical drawing, plane geometry, geometrical drawing, tools/materials, and related workbook activities.

The tutor should retrieve the relevant page/topic rather than treating the entire document as a single generic answer. For uploaded worksheet photographs, the AI should identify the page/topic, read visible instructions and dimensions, and generate an appropriate step-by-step solution in the CAD workspace where applicable.

## Repository note

The original PDFs are maintained as research/source documents. They should only be distributed through this repository where the repository owner has the necessary permission/licence. The current GitHub integration can write text files directly, but does not provide a binary-file upload operation for multi-megabyte PDFs; the original PDFs therefore still need to be uploaded through Git/Git LFS from the authorised local research copy.
